KIRAN ZAHID — FRESH PORTFOLIO PACKAGE

LOCAL TEST (NO PYTHON / NO NODE / NO INSTALLATION)
1. Extract this ZIP.
2. Open the extracted Kiran-Zahid-Portfolio-Fresh folder.
3. Double-click index.html. It opens directly in your browser.
4. Check the navigation, project images, CV download, and contact links.
5. To test the CV separately, double-click Kiran-Zahid-CV.pdf.

The local preview uses the built-in HTML content, so it does not need a local web server. GitHub Pages loads content.json when the site is published. Keep all folders (assets, fonts, admin) beside index.html.

GITHUB PUBLISHING
1. Create a new PUBLIC repository. For a project site, the repository name can be any available name.
2. Extract this ZIP and upload the CONTENTS of this folder directly to the repository root. Do not upload the ZIP or the enclosing folder.
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then save.
4. Wait for deployment and open the Pages URL shown by GitHub.

FILES INCLUDED
- index.html, style.css, script.js: website
- content.json: editable structured content used by GitHub Pages
- Kiran-Zahid-CV.pdf and cv.html: CV download and printable CV page
- assets/: only current portfolio images and AQSA POS evidence
- fonts/: local website fonts and their licences
- admin/index.html: local JSON import/edit/export helper
- 404.html, favicon.svg, apple-touch-icon.png, og-image.png: site support files
