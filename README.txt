IMPORTANT PRIVACY / LIMITATION
This is a local static website. The dashboard is for convenient editing on the same browser/device and is not a password-protected online admin system. Changes are stored in browser localStorage; they do not update the ZIP files automatically and may not appear in another browser or device. To publish changes elsewhere, edit the files or make a new ZIP after editing.

OPTIONAL CONTENT MANAGER
After logging in to Edit portfolio, use “Add to your portfolio” to add optional education history, certificates, projects, or other items. Each item can have a title, description, clickable URL, and an optional picture, video, or document attachment. Leave any field blank if you do not need it. Items are stored in the current browser and can be removed from the dashboard. Keep attachments under 1.8 MB for local browser storage compatibility.
