# Project repository links

The portfolio supports a per-project GitHub source link through the `repository` field in `content.json`. The current supplied project materials contain workflow screenshots and AQSA POS testing evidence, but no verified public repository URLs or exportable n8n workflow JSON files.

For that reason, this update deliberately does not point project buttons to the general GitHub profile or invent repository URLs. Add a real public repository URL to the matching project's `repository` field when its source files are published. The website will then display a **View source on GitHub** link automatically.
