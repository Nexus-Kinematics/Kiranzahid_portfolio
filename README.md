# Kiran Zahid — New Portfolio

A new responsive portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — public portfolio
- `styles.css` — responsive design system
- `script.js` — mobile navigation and current year
- `Kiran-Zahid-CV.pdf` — generated CV
- `admin/index.html` — local-only editor demonstration
- `assets/images/favicon.svg` — favicon

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## GitHub Pages
Upload the project files and folders to the root of the repository's `main` branch, preserving paths. Keep the repository name and URL unchanged: https://nexus-kinematics.github.io/Kiranzahid_portfolio/
